## 🛠️ التعديلات والإضافات المطلوبة

### 1. إضافة شهاداتك ✅

في ملف **about.html**، ابحث عن:
```html
<div class="certificate-placeholder">
```

**كيفية الإضافة:**
- احفظ صورة الشهادة باسم: `certificate-1.jpg`
- استبدل الجزء بـ:
```html
<img src="certificate-1.jpg" alt="شهادة التداول" class="certificate-image">
```

### 2. استبدال شعار بـ base64 بصورة حقيقية

ابحث في كل صفحة عن:
```html
<img src="data:image/jpeg;base64..." alt="E-TRADING Logo">
```

استبدله بـ:
```html
<img src="logo.png" alt="E-TRADING Logo">
```

### 3. إضافة فيديوهات الدورات

في `basic-course.html` و `smc-course.html`، أضف:
```html
<div class="video-container">
    <iframe width="100%" height="400" 
            src="https://www.youtube.com/embed/VIDEO_ID" 
            frameborder="0" allowfullscreen></iframe>
</div>
```
